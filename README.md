# Zero Trust Security - Sistem Nilai

Project praktikum Keamanan Informasi untuk membangun Sistem Nilai berbasis backend dengan prinsip Zero Trust Security.

## Rencana komponen

- API Gateway (port 3000) sebagai Policy Enforcement Point (PEP).
- Service Nilai (port 3001) untuk pengelolaan nilai dan finalisasi kelas.
- Service Transkrip (port 3002) untuk pengelolaan transkrip mahasiswa.
- SQLite sebagai database bersama.

Project akan dikembangkan secara bertahap. Detail instalasi, konfigurasi, endpoint, akun pengujian, dan cara menjalankan akan dilengkapi selama pengerjaan.
